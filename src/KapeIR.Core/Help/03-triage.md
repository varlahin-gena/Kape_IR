# Triage и режимы сбора

Полевой EXE (или распакованный пакет) запускается **от администратора** (UAC).

## Оценка объёма

Кнопка оценки запускает KAPE с `--sim`: файлы **не копируются**, в журнале появляется сводка (см. раздел «Оценка объёма»).

## Полный сбор

Копирование по выбранным Targets, затем Modules (если заданы), опционально ZIP результатов.

## Типичные опции

- **Диск источника** — том целевой системы (часто `C:`).
- **Папка RESULTS** — куда писать evidence.
- **Case ID** — попадает в `collection_log.txt` и `chain_of_custody.txt`.
- **Двухфазный IR** — сначала volatile (фаза 1), затем диск (фаза 2).
- **Skip memory** — фаза 1 без дампа RAM (осознанный выбор).

Silent / EDR CLI (кратко): `--silent`, `--sim-only`, `--tsource`, `--case-id`, `--phase`, `--skip-memory`. Коды выхода: `0` OK, `1` сбой сбора, `2` аргументы/payload, `3` подготовка.
