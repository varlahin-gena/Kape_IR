# Triage и режимы сбора

Полевой EXE (или распакованный пакет) запускается **от администратора** (UAC).

Смысл фаз 1a / 1b / 2 и список compounds — в разделе **«Двухфазный IR / Phase1»**.

## Оценка объёма

Кнопка оценки запускает KAPE с `--sim`: файлы **не копируются**, в журнале появляется сводка (см. раздел «Оценка объёма»).

## Полный сбор

Копирование по выбранным Targets, затем Modules (если заданы), опционально ZIP результатов. В two_phase — сначала Phase1, затем диск.

## Опции двухфазного запуска

| Опция | Дамп (1a) | Vol3 (1b) |
|-------|-----------|-----------|
| (по умолчанию) | да | да |
| **Без пост-анализа памяти (Vol3)** / `--skip-memory-analysis` | да | нет |
| **Без дампа памяти** / `--skip-memory` | нет (`Phase1_VolatileFirst_NoMemory`) | нет |
| **Только фаза 1** / `--phase 1` | по флагам выше | по флагам выше |
| **Только фаза 2** / `--phase 2` | — | — |

Чекбокс пост-анализа недоступен, если включён «Без дампа памяти».

## Прочие опции

- **Диск источника** — том целевой системы (часто `C:`).
- **Папка RESULTS** — куда писать evidence.
- **Case ID** — попадает в `collection_log.txt` и `chain_of_custody.txt`.

Silent / EDR CLI (кратко): `--silent`, `--sim-only`, `--tsource`, `--case-id`, `--phase`, `--skip-memory`, `--skip-memory-analysis`, `--verify`.  
Коды выхода: `0` OK, `1` сбой сбора, `2` аргументы/payload/verify, `3` подготовка.
