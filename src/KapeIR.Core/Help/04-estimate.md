# Оценка объёма

После `--sim` в журнале Triage появляется сводка, например:

- `Файлов найдено: 982`
- `К копированию (sim): 737 (дедуп 245, из 982)`
- `Отложено (locked): 196`
- `Файлы не копировались (--sim).`

## Как читать числа

- **Найдено** — путей после expand таргетов (кандидаты).
- **К копированию** — уникальные файлы, которые пойдут в реальный сбор.
- **Дедуп** — повторы одного пути из нескольких таргетов; копируется один раз.
- **Отложено (locked)** — заняты ОС на первом проходе (часто `.evtx` / `.etl`); KAPE откладывает и обычно **всё равно** забирает позже.

Связь: **к копированию + дедуп = найдено**. Locked — не «потерянные» файлы, а подмножество процесса копирования.

Ориентир по месту на диске — по числу/размеру уникальных файлов «к копированию» (модули и ZIP добавляют объём сверху).
